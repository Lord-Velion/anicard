## Что это за проект

**AniCard** – это упрощённая backend-копия функционала Koikatsu DB. Проект реализован в виде REST API и позволяет:

- **Гостям (неавторизованным пользователям):**
  - Регистрироваться и входить (получать JWT-токен).
  - Просматривать списки карточек персонажей и одежды с пагинацией.
  - Искать по имени, фильтровать по тегам, полу, типу личности (для персонажей).
  - Сортировать по популярности или дате (возрастание/убывание).
  - Смотреть детальную информацию (описание, теги, автор).
  - Скачивать PNG-файлы карточек персонажей и одежды.

- **Зарегистрированным пользователям (в дополнение к возможностям гостя):**
  - Выходить из системы.
  - Просматривать и редактировать свой профиль (email, пароль).
  - Загружать новые карточки персонажей и одежды (PNG + описание + теги).
  - Редактировать описание и теги своих материалов.
  - Удалять свои карточки персонажей и одежды.

Проект создан в портфолио для демонстрации навыков на собеседованиях.

### 🤖 Использование ИИ-агента при разработке

Этот проект создавался с помощью LLM-агента (opencode). ИИ использовался для:

- генерации шаблонного кода (контроллеры, DTO, интерфейсы сервисов);
- помощи в выборе архитектурных решений (например, `IKKLoaderService` + `HttpClientFactory`);
- написания повторяющихся частей (заглушки репозиториев, классы исключений);
- рефакторинга и добавления валидации.

**Весь сгенерированный код был проверен, осмыслен и протестирован мной.**  
ИИ выступал в роли ускорителя, а не автора.
